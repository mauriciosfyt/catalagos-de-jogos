# Catálogos de Jogos

Bem-vindo ao repositório **Catálogos de Jogos**! Este projeto tem como objetivo criar um catálogo interativo para exibição e organização de jogos.

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **JavaScript** (59.4%)
- **HTML** (21.9%)
- **CSS** (18.7%)

## 📋 Funcionalidades

- Adicionar jogos ao catálogo.
- Editar informações de jogos existentes.
- Visualizar detalhes dos jogos.
- Remover jogos do catálogo.
